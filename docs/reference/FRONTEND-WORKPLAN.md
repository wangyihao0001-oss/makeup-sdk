## 5. 实现时必须保留的规则

- 导航固定为广场、试衣、试妆、我的；P01—P14、M01—M05、S01—S03 和最小 O01 均在本人范围。视觉以 DESIGN.md 和最新设计说明为准，旧版酒红规范不作为当前颜色基线。

- 问题 60 字；说明/评论/回应/追加说明 500 字；决定原因 200 字；价格选填 0.01—999999.99 元、最多两位小数；顾虑最多 3 项。客户端与 B1 使用一致计数与空值规则，后台校验仍是最终约束。
- 亲友与公开各自预览、主动确认；登录成功不自动公开。亲友接收者只能看到本人意见及作者对应回应，不能显示总票数、其他接收者身份或反馈。
- 分享卡片封面中性；导出图带 AI 标识与能力提示，不含人像原图、他人意见或令牌。微信分享入口打开不当作送达，相册成功以真实回执为准。
- 试妆六类为口红/睫毛/眼线/眼影/腮红/底妆；眼线类别键沿用 eyeline。使用实际纹样稳定 ID，不以示例名称或数组序号当标识；不增加浓度、脸型、模糊或自动美颜。
- 相机只在主动开启后初始化，后台/离开/销毁释放；无人脸、多人、遮挡或光线不足禁拍。按住对比在释放/取消/失焦/后台后恢复，不改配置；只导出当前帧，设备不支持不自动走云端。
- 历史试妆查看不覆盖编辑态，继续调整需用户主动选择。删除要展示引用与影响、逐项结果；私人副本删除不能被描述为撤回所有公开内容或相册副本。
